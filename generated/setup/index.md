Pick the agent you already use. Every page leads with the best way to connect it and lists
the others, and the same Spacefast account works across all of them.

- [Claude Code](/setup/claude-code/): Add Spacefast to Claude Code so it can publish what you build.
- [ChatGPT](/setup/chatgpt/): Add Spacefast to ChatGPT on the web so it can publish what you build.
- [Grok Bot](/setup/grok-bot/): Ask your Grok Bot to add Spacefast, or add the Spacefast plugin.
- [Muse](/setup/muse/): Give Muse one prompt and it sets up Spacefast itself.
- [Antigravity](/setup/antigravity/): Add Spacefast to Antigravity so its agent can publish what you build.
- [Cursor](/setup/cursor/): Add Spacefast to Cursor so its agent can publish what you build.
- [Raycast](/setup/raycast/): Add Spacefast to Raycast AI and call it with @Spacefast.
- [Any MCP client](/setup/any-mcp/): Connect any app that speaks MCP: run Spacefast on your computer, or point the app at the hosted server.

## More agents

- [Claude Desktop](/setup/claude-desktop/): Add Spacefast to the Claude desktop app on this computer.
- [Claude](/setup/claude-app/): Add Spacefast to your Claude account once, and use it on the web, your phone, the desktop app, and Cowork.
- [Claude Cowork](/setup/claude-cowork/): Add Spacefast to your Claude account so Cowork tasks can publish what they make.
- [ChatGPT Work](/setup/chatgpt-work/): Add the Spacefast plugin so ChatGPT Work can publish what it makes.
- [Codex](/setup/codex/): Add Spacefast to Codex so it can publish what you build, on your computer or in the cloud.
- [dots and ChatGPT Space](/setup/chatgpt-space/): Add the Spacefast plugin to your ChatGPT account so your dot can publish what it makes.
- [Windsurf](/setup/windsurf/): Windsurf is now Devin Desktop, the same app after an update. Add Spacefast to it so its agent can publish what you build.
- [VS Code](/setup/vscode/): Add Spacefast to VS Code so Copilot can publish from agent mode.
- [GitHub Copilot CLI](/setup/github-copilot/): Add Spacefast to GitHub Copilot CLI so it can publish from your terminal.
- [GitHub Copilot app](/setup/github-copilot-app/): Add Spacefast to the GitHub Copilot app so its agents can publish what you build.
- [OpenCode](/setup/opencode/): Add Spacefast to OpenCode so it can publish what you build.
- [Zed](/setup/zed/): Add Spacefast to Zed so its agent can publish what you build.
- [Devin Desktop](/setup/devin-desktop/): Add Spacefast to Devin Desktop, formerly Windsurf, for its Devin Local agent and Devin CLI.
- [Devin Cloud](/setup/devin-cloud/): Add Spacefast to Devin Cloud so your sessions can publish what you build.
- [Grok Build](/setup/grok-build/): Add Spacefast's remote MCP server to Grok Build.
- [OpenClaw](/setup/openclaw/): Add Spacefast to OpenClaw as an MCP server, or give OpenClaw one prompt and it sets Spacefast up itself.
- [Hermes](/setup/hermes/): Add Spacefast to Hermes as an MCP server, or give Hermes one prompt and it sets Spacefast up itself.
- [Pi](/setup/pi/): Add Spacefast to Pi as an MCP server, or add the Spacefast skill.
- [Conductor](/setup/conductor/): Conductor runs Claude Code and Codex side by side on your Mac. Add Spacefast to Claude Code once and every Conductor workspace has it.
- [Instinct](/setup/instinct/): Give Instinct one prompt and it sets up Spacefast itself.
- [Perplexity](/setup/perplexity/): Add Spacefast to Perplexity as a custom connector.
- [Microsoft Copilot](/setup/microsoft-copilot/): Microsoft Copilot can't connect to Spacefast yet. Copy the setup prompt to try it.
- [T3 Chat](/setup/t3-chat/): T3 Chat has no MCP or connectors. Pick an agent below that does, and publish from there.
- [Amp](/setup/amp/): Add Spacefast to Amp so it can publish what you build.
- [Warp](/setup/warp/): Add Spacefast to Warp so its agents can publish what you build.
- [Factory Droid](/setup/factory-droid/): Add Spacefast to Factory Droid so it can publish what you build.
- [Cline](/setup/cline/): Add Spacefast to Cline so it can publish what you build.
- [Indent](/setup/indent/): Add Spacefast to Indent so it can publish what you build.
- [Poke](/setup/poke/): Add Spacefast to Poke so it can publish for you.
- [Grok](/setup/grok/): Connect Spacefast to Grok through a custom MCP connector.

## No longer supported

- [Gemini CLI](/setup/gemini-cli/): use Antigravity instead.
- [Continue](/setup/continue/): use Cursor instead.
- [Roo Code](/setup/roo-code/): use Cline instead.
- [Jules](/setup/jules/): use Antigravity instead.

Anything else that can fetch a URL can publish too: point it at the [agent documentation](/agents/).
