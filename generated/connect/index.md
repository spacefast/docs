There are a few ways to connect an agent to Spacefast. Your agent's [setup page](/agents/) says which one to use first. These pages explain each one.

- [Directory connector](/connect/directory-connector/): Add Spacefast from the agent's own connector directory, then sign in.
- [Marketplace listing](/connect/marketplace/): Install the Spacefast plugin from the agent's official plugin marketplace.
- [Spacefast plugin](/connect/plugin/): Add the plugin from spacefast/plugins with the agent's own plugin command.
- [MCP on your computer (stdio)](/connect/stdio-mcp/): Run the Spacefast MCP server locally on your computer over stdio.
- [Hosted MCP server](/connect/hosted-mcp/): Point the agent at https://mcp.spacefast.com and sign in with OAuth.
- [Prompt link](/connect/prompt-link/): A link that opens the agent with a setup prompt already typed in.
- [Setup prompt](/connect/setup-prompt/): Paste one prompt into any agent. It reads spacefast.com/setup.md and sets itself up.
- [Spacefast CLI](/connect/cli-setup/): Run the Spacefast CLI setup command, which detects your agents and configures each one.
- [Skill only](/connect/skill/): Install just the Spacefast skill, which teaches an agent to publish through the API.
- [Desktop extension](/connect/desktop-extension/): Download a file that installs Spacefast into the Claude desktop app on this computer.
- [GitHub MCP Registry](/connect/github-mcp-registry/): Install Spacefast from its page on github.com/mcp.
- [Git push](/connect/git-push/): Push a Git repository to an existing Space's remote to publish it.
