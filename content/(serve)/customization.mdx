Customization settings are saved on the Space, not on a version, and they override the `theme` and `meta` in your `sf.jsonc`.

Open the Space and go to **Customization**. It has four tabs: **Theme**, **Search & sharing**, **Google Analytics**, and **Custom JS**. A preview labeled **Visitor sees** shows your unsaved changes beside the controls.

## What lives on the Space, not the version

Because these settings are stored on the Space, they stay in place through publishes and rollbacks. They also override the published `sf.jsonc`: the Space's `theme` replaces the file's `theme` instead of merging with it. If your config sets `theme` and you also edit the Theme tab, the dashboard values win until you clear them. The same applies to `meta`.

Theme and share metadata apply without republishing: the next request after you save gets them. **Custom JS** is different. A script change takes effect on the next publish.

The four tabs write `meta`, `theme`, and `superpowers` in the Space's config. The same keys are documented in the [`sf.jsonc` reference](/config-file), and the [`updateSpace`](/api/reference/spaces/updatespace) operation is what the dashboard calls.

## Theme

Every field is optional. A blank field uses the platform default.

| Group | Field | Config key | What it does |
| --- | --- | --- | --- |
| Brand | **Logo** | `theme.logo` | Shown at 28px beside your name on every Spacefast-drawn page. An `https://` URL or a root-relative path, up to 2000 characters |
| Brand | **Display name** | `theme.name` | The name in the brand row, 1 to 120 characters |
| Color | **Accent** | `theme.accent` | Buttons and fills. Placeholder `#ea580c` |
| Color | **Background** | `theme.background` | Page background. Blank follows the visitor |
| Type | **Font stack** | `theme.font` | A plain CSS font-family stack, no imports, up to 256 characters |
| Badge | **Hide "Powered by Spacefast"** | `theme.hideSpacefastBranding` | Removes the badge from the pages Spacefast draws |

Colors accept hex, `rgb()`, `rgba()`, `hsl()`, `hsla()`, and CSS color names, up to 64 characters. Uploading a logo stages the file, and the field says it uploads to your Space when you save. A logo path that is not in the live version warns "This path isn't in your live version yet."

### The background pins the color scheme

With **Background** blank, pages follow each visitor's device setting, light or dark.

Set a background and Spacefast decides whether that color is light or dark, then serves that one scheme to every visitor. The field shows **Pinned.** and a **Clear to follow visitors again** option. In the preview, a locked **Pinned · Dark** or **Pinned · Light** label replaces the Auto/Light/Dark switcher.

### Check the branding entitlement

The dashboard enables badge removal when the team has the branding entitlement or the Space used badge removal before the new plans took effect. Other Spaces need the entitlement.

Publishing checks this too. Publishing a version whose effective theme sets `hideSpacefastBranding` without either allowance fails with `hide_spacefast_branding_not_entitled` and the message "theme.hideSpacefastBranding is not included on this plan."

### Code override

These controls don't restyle a page that your version ships as its own file. The preview marks that page **Code override.** and points at its `_pages/<id>.html` file. See [Layout, theme, and site pages](/site-pages).

## Search and sharing

What a browser tab, a link unfurl, and a search result show.

| Field | Config key | Cap |
| --- | --- | --- |
| **Title** | `meta.title` | 300 characters |
| **Description** | `meta.description` | 1000 characters |
| **Social image** | `meta.image` | 2000 characters |
| **Favicon** | `meta.favicon` | 2000 characters |

A 1200 × 630 social image fills the card exactly. Favicon takes an upload or a path. A value longer than most previews can show is still saved, with a note under the field that it will be cut off.

**Import from a live page** under **Shortcut** pulls title, description, and image from a page you have already published. Give it a path and press **Fetch**.

Two previews sit beside the fields, **Link unfurl · iMessage, Slack, X** and **Search result**.

## Analytics tags

The **Google Analytics** tab holds two cards, **Google Analytics** and **Google Tag Manager**. Each has a **Collect analytics** switch and one id field.

| Card | Field | Config key | Accepted |
| --- | --- | --- | --- |
| Google Analytics | **Measurement ID** | `superpowers.googleAnalytics.measurementId` | `G-`, `GT-`, `AW-`, `DC-`, or `UA-`, then letters or digits joined by single `_` or `-` |
| Google Tag Manager | **Container ID** | `superpowers.googleTagManager.containerId` | `GTM-`, then letters or digits joined by single `_` or `-` |

Saving an ID that doesn't match fails, and the card shows **Invalid ID**. A card with its switch off shows **Off** and sends nothing. With the switch on and a valid ID, the card shows **Enabled** and the tag loads on every published page.

### Page enhancements has to be on first

Analytics and custom code only load when the Space's **Page enhancements** switch is on. With it off, both tabs show **Page enhancements is off.**, every control is disabled, and an **Enable page enhancements** button turns it on.

The switch is in **Settings** under **Page enhancements**. It controls the performance, SEO, analytics, and comment features Spacefast adds to published pages. Turning it off keeps your saved settings. When it's on, an **Active now** row lists what is being added.

## Custom JS

One card, **Site-wide JavaScript**, with a **Run custom code** switch and a **JavaScript** textarea. The script applies to every published page view and is stored as the first entry in `superpowers.javascriptTags`.

Don't include `<script>` tags. Changes take effect on the next publish. A snippet can be up to 8 KiB.

:::warning[Custom code runs with your page]
Only paste code you trust. A broken script can break the page for visitors.
:::

## Copy as spacefast.jsonc

The **Copy as spacefast.jsonc** button in the header copies your current draft as JSON. It includes only the `meta` and `theme` objects, without empty fields:

```jsonc sf.jsonc
{
  "meta": {
    "title": "My App",
    "description": "What this site is",
    "image": "/og.png",
    "favicon": "/favicon.ico"
  },
  "theme": {
    "name": "My App",
    "logo": "/logo.svg",
    "accent": "#0d9488",
    "background": "#ffffff",
    "font": "Inter, system-ui, sans-serif"
  }
}
```

Paste it into your project's `sf.jsonc` to keep those settings in the repository. The button says `spacefast.jsonc`, an older filename that still works, but the current name is `sf.jsonc`.

While the Space has its own `theme`, it still overrides the file. Clear the Theme tab's fields if you want the file to control the theme.
