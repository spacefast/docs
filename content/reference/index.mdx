## Troubleshooting

Find the symptom and follow the link.

- **A domain does not resolve or serve the space**: run `sf domains check`
  and `sf domains diagnostics`, then fix the records diagnostics reports.
  See [Verify DNS and SSL](/domains#verify-dns-and-ssl).
- **The homepage is missing**: the folder or zip needs `index.html` at the
  root. See [What serves the homepage](/publish#what-serves-the-homepage).
- **An upload or finalize fails**: retry the publish. A publish rejected
  over the storage quota does not affect the live site. See
  [Retention and storage](/publish/versions#retention-and-storage).
- **A bad publish is live**: promote a known-good version. See
  [Promote and roll back](/publish/versions#promote-and-roll-back).
- **A version URL asks for sign-in**: the live URL is not affected. See
  [Permanent version URLs](/publish/versions#permanent-version-urls).
- **Every page asks for a password**: space password protection is on, and
  Spacefast [rejects `_headers` Basic Auth](/serve/headers#no-basic-auth).
  See [Control who can visit](/share).
- **The CLI misbehaves locally**: [`sf doctor`](/cli#sf-doctor) checks
  local state, auth, API reachability, and the current space link.
