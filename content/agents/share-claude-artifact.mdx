---
title: Share a Claude artifact publicly
description: Export a Claude artifact as website files, publish it to Spacefast, and give anyone with the share link access
---

Export your Claude artifact as website files, publish the folder to Spacefast, then enable public access. Anyone with the share link can open the published site without a Claude account.

If you want to share the artifact inside Claude instead, use Claude's own sharing controls. This guide publishes a separate website from exported files. It does not publish your conversation.

## Export a working page

Download the artifact's files from Claude. A standalone HTML page needs an `index.html` file. If you have a component rather than a complete page, ask Claude to turn it into a working website first, including its styles and dependencies.

Open the exported page locally and check its images and interactions. Features that depend on Claude's chat or private files need their own implementation in the exported site. For a framework project, follow [Frameworks and builds](/frameworks) to produce the directory to publish.

## Publish the folder

Open [Drop](https://my.spacefast.com/drop) and upload the folder. You can publish without an account. Keep the returned claim link and open it to claim the Space before anonymous expiry; see [Publish without an account](/anonymous-and-claim).

Already working in an agent with Spacefast connected? Ask:

<Prompt description="Publish my exported artifact and make it public." actions={["copy"]}>
Publish this exported website to Spacefast, enable public access, and give me the live URL and claim link if it needs claiming.
</Prompt>

See [Claude Code setup](/agents/claude-code) or [Claude Desktop setup](/agents/claude-desktop) if the connection is missing.

## Choose who can open it

New personal Spaces are private by default. In the Space's **Access** settings, enable public access before sending the live URL. Public means anyone with the share link can view the site. A bare URL to a private Space does not grant access.

For a restricted audience, keep the Space private and create a viewer link instead. [Access and sharing](/access) explains the choices and how to revoke access.

## Update the same link

Publish the changed files to the same Space. Its live address stays the same, so recipients can keep using the link you sent. [Versions and rollback](/versions) explains retained versions and restoring an earlier one.

To use your own address, [attach a custom domain](/domains). Check [Plans and billing](/billing) for the current plan allowances before choosing a plan.
