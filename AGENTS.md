# Repository instructions

This repository is the public source of truth for Spacefast documentation.
Assume every commit and every line of history will be public.

## Content

- Document shipped, publicly verifiable behavior only. Do not guess commands,
  flags, routes, defaults, or timelines.
- Keep the voice direct, no-BS, and a little playful. Prefer the best path over
  an encyclopedia of alternatives.
- Do not add navigation to a section until that section has a real page or
  generated source.
- Test behavior and built output. Do not read implementation source and assert
  that a string exists as a substitute for exercising the result.

## Public safety

- Never add links or history from a non-public monorepo, private pull requests
  or workflow runs, credentials or other secrets, local absolute paths, or
  private repository metadata.
- Do not copy private commit IDs, branch names, issue references, code comments,
  or filesystem paths into docs, examples, fixtures, workflow logs, or commit
  messages.
- Use public URLs and repository-relative paths. Treat examples as production
  copy: placeholders must be obvious placeholders, never real credentials.
- Run `bun run verify:public-safety` before handing off changes.

## Generated ownership

- `generated/openapi/**`, `generated/errors/**`, `generated/cli/**`, and
  `generated/redirects.json` are one producer-owned snapshot. The exporter owns
  every file there, including the manifest and ownership marker. Do not
  hand-edit them.
- `.blume/**` and `dist/**` are generated by Blume. Never edit or commit them.
- `content/cli/**`, `content/errors/**`, and `public/_redirects` are ignored
  build overlays materialized from the verified snapshot. Do not hand-edit
  them.
- `public/spacefast.jsonc` is authored here and copied to
  `dist/spacefast.jsonc` by the static build so the published artifact carries
  its serving config.

## Verification

Use Bun 1.3.11 and Node.js 24 or newer, then run:

```bash
bun install --frozen-lockfile
bun run verify:generated
bun run check
bun run validate
bun run build
bun run verify:public-safety
bun run verify:routes
```
