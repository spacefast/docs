Push a Git repository to an existing Space's remote to publish it.

## How it works

1. Add the Space's returned Git remote.
2. Push. Spacefast builds and publishes the commit.

## What you need

- An existing Space and an API key in a Git credential helper.

## Best for

Publishing updates after setup, from any agent with a shell.
