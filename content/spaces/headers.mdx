---
title: Headers
description: How to configure response headers for static files served by Spacefast.
---

Add `_headers` at the publish root to set or remove response headers. Spacefast compiles the file when a publish finishes and attaches the rules to that immutable version. Serving is precomputed, and the file itself is never served.

Use space password protection for simple gated access. Use `_headers` Basic
Auth when you need file-based credentials in the routing config and the team
has that entitlement.

```text
/*
  X-Frame-Options: DENY
  Referrer-Policy: no-referrer

/assets/*
  Cache-Control: public, max-age=31536000, immutable
```

## Block syntax

Each block starts with a path or URL matcher. Indented lines apply to matching responses.

```text
matcher
  Header-Name: value
  ! Header-To-Remove
  !Header-To-Remove
```

- Lines beginning with `#` are comments.
- Matchers must start at the beginning of the line. Header operations must be indented with a space or tab.
- Header names may contain letters, numbers, and `-`.
- Each line can be up to 2,000 characters.
- A publish can include up to 100 header matcher blocks.

## Matchers

Matchers can be absolute paths beginning with `/` or absolute `http`/`https` URLs. URL matchers can include host patterns but not ports.

```text
/*
  X-Content-Type-Options: nosniff

/assets/*
  Cache-Control: public, max-age=31536000, immutable

https://www.example.com/docs/*
  X-Robots-Tag: index, follow

https://*.example.com/private/*
  X-Robots-Tag: noindex
```

Patterns support `*` splats and named placeholders such as `:slug`. Header matchers also allow wildcard prefixes inside a segment, such as `*.example.com`.

```text
/blog/:slug
  Link: </feed.xml>; rel="alternate"
  X-Page-Slug: :slug

/files/*.pdf
  Content-Disposition: inline

https://:team.example.com/app/*
  X-Team-Site: :team
```

- Only one wildcard is supported per matcher.
- Wildcards must appear at the end of a segment, unless used as a matcher prefix.
- Wildcards and placeholders cannot be used in the same segment.
- Placeholder names must start with a letter and can be captured only once per matcher.

## Set headers

Set a header with an indented `Name: value` line. Header names are canonicalized: `x-frame-options` becomes `X-Frame-Options`.

```text
/*
  X-Frame-Options: DENY
  X-Content-Type-Options: nosniff
  Permissions-Policy: geolocation=(), microphone=()
  Referrer-Policy: strict-origin-when-cross-origin

/fonts/*
  Access-Control-Allow-Origin: *
  Timing-Allow-Origin: *
```

## Remove headers

Prefix the header name with `!` to remove a response header from matching paths.

```text
/downloads/*
  ! X-Robots-Tag
  Cache-Control: no-store

/legacy/*
  !Link
```

## Runtime order

All matching blocks apply in file order against the original request path. Captures from path and host matchers expand in header values. Duplicate set operations for the same header are comma-joined. Remove operations delete previously applied values, and a later set can add the header again.

```text
/*
  X-Trace: base

/docs/:slug
  X-Trace: docs
  X-Page: :slug

/docs/private
  ! X-Trace
  X-Trace: private
```

Headers apply to runtime-served file responses, including internal rewrites and custom 404 files. They do not apply to browser redirects or external proxy responses.

## Basic Auth

Basic Auth requires the corresponding team entitlement. The dashboard and
[plan policy](/account/limits) show whether it is enabled.

Use `Basic-Auth` to protect matching paths. Credentials are one or more space-separated `username:password` pairs. Credentials are converted to hashed runtime metadata at compile time; `Basic-Auth` is never sent in the response.

```text
/preview/*
  Basic-Auth: EXAMPLE_USER:EXAMPLE_PASSWORD

/staging/*
  Basic-Auth: EXAMPLE_USER_ONE:EXAMPLE_PASSWORD_ONE EXAMPLE_USER_TWO:EXAMPLE_PASSWORD_TWO
```

These values are placeholders. Never commit production credentials to
`_headers` or repository history; compile-time hashing protects runtime
metadata, not the source file or earlier versions.

- Username cannot contain `:` or whitespace.
- Password cannot contain whitespace and must be non-empty.
- `! Basic-Auth` is invalid because Basic Auth must be configured with credentials.

Anonymous spaces cannot use Basic Auth. Claim the space first. Space-level
password protection is a separate access setting.

## Unsupported headers

Spacefast manages connection, transport, cookie, redirect, range, and edge cache behavior. These headers cannot be changed from `_headers`.

| Header group     | Headers                                                                                                                                                                                                                                  |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Platform-managed | `Accept-Ranges`, `Age`, `Allow`, `Alt-Svc`, `Connection`, `Content-Encoding`, `Content-Length`, `Content-Range`, `Date`, `Location`, `Server`, `Set-Cookie`, `Strict-Transport-Security`, `Trailer`, `Transfer-Encoding`, and `Upgrade`. |
| Edge cache       | `CDN-Cache-Control`, `Cloudflare-CDN-Cache-Control`, `Netlify-CDN-Cache-Control`, and `Surrogate-Control`.                                                                                                                               |

`Cache-Control` is allowed for browser responses. Spacefast preserves owner intent such as `no-store`, `no-cache`, `private`, and `immutable`; for public revalidating files it may add shared-cache directives such as `s-maxage` and mirror the final policy into provider edge-cache headers so the browser can revalidate while the edge can serve repeat requests.

## Invalid rules

```text
# Matcher must start with / or use an absolute URL
assets/*
  Cache-Control: public

# Header operations must be inside a matcher block
  X-Frame-Options: DENY

# Header operations need Name: value
/*
  X-Frame-Options DENY

# URL matchers cannot include ports
https://example.com:8443/*
  X-Robots-Tag: noindex

# These are managed by Spacefast
/*
  Set-Cookie: session=abc
  Strict-Transport-Security: max-age=31536000
  CDN-Cache-Control: max-age=60
```

Redirects, rewrites, proxy routes, and custom 404 rules use a separate [Redirects](/spaces/redirects) page.
