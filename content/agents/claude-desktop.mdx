Add Spacefast to Claude Desktop so it can publish files and read your Spaces. The plugin is the recommended way. The desktop extension runs the server on your computer instead.

## Add the Spacefast plugin

The plugin carries the hosted Spacefast MCP server and the Spacefast skills. You add it once to your Claude account, so it works in the Chat and Cowork tabs, on claude.ai, and in Claude Code signed in with the same account.

<Steps>
  <Step title="Open the Plugins page">
    In Claude, open Customize → Plugins, then choose Add → Add marketplace → Add from a repository.
  </Step>
  <Step title="Add the Spacefast marketplace">
    Paste `spacefast/plugins` and add the marketplace.
  </Step>
  <Step title="Add the plugin">
    Select the Spacefast plugin, then choose Add.
  </Step>
  <Step title="Sign in">
    Sign in to Spacefast and approve access when Claude asks.
  </Step>
</Steps>

Plugins need a paid Claude plan. On a Team or Enterprise plan, an owner may limit which marketplaces you can add. See [Use plugins in Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

You can also add only the connector: on claude.ai, open Customize → Connectors, choose + → Add custom connector, name it Spacefast, and use `https://mcp.spacefast.com` as its URL.

Then ask for something small to prove Spacefast is connected.

<Prompt description="Publish this folder to Spacefast and give me the live URL." actions={["copy"]}>
Publish this folder to Spacefast and give me the live URL.
</Prompt>

## Install the desktop extension

The extension runs the Spacefast MCP server on your computer, so `publish` can read local files. It starts the server with `npx`, so it needs Node.js 20.3 or newer with `npx` installed where Claude Desktop can find it.

<Steps>
  <Step title="Download the bundle">
    Download `claude-desktop.mcpb` from the latest release of `github.com/spacefast/plugins`.
  </Step>
  <Step title="Double-click it">
    Claude Desktop reads the manifest and offers to install the extension.
  </Step>
  <Step title="Leave the key blank, or paste one">
    The extension has one setting, a Spacefast API key. Leave it empty to publish anonymously and claim the Space later.
  </Step>
</Steps>

If Claude Desktop shows "Server disconnected" or "Unable to connect to extension server", open `~/Library/Logs/Claude/mcp-server-Spacefast.log` on macOS. `spawn npx ENOENT` means Claude Desktop cannot find `npx`. This happens when Node.js comes from Homebrew or a Node version manager. Use the plugin instead.

## What the manifest declares

The bundle is a manifest version `0.2` extension with a Node server. Its entry point is `server/index.js`, which is a thin spawner. It launches the Spacefast MCP server over stdio through `npx`, so the extension itself carries no server code.

```json manifest.json
"mcp_config": {
  "command": "node",
  "args": ["${__dirname}/server/index.js"],
  "env": {
    "SPACEFAST_TOKEN": "${user_config.api_token}"
  }
}
```

Because the server runs locally, it can read files. `publish` takes a path or the current directory, not only inline files.

| Fact | Value |
|---|---|
| Manifest version | `0.2` |
| Server type | `node` |
| Platforms | macOS, Windows, Linux |
| Node | 20 or newer (the CLI it launches needs 20.3 or newer) |
| License | MIT |
| Tools declared | The nine Spacefast MCP tools |

## Authentication

The extension exposes one user setting.

| Setting | Type | Required | What it does |
|---|---|---|---|
| Spacefast API key | string, marked sensitive | No | "Your Spacefast API key (from https://my.spacefast.com/account/api-keys). Leave blank to publish anonymously." |

The value is passed to the server as `SPACEFAST_TOKEN` and never written into a config file you have to manage.

Leaving it blank is a real workflow, not a degraded one. An anonymous publish returns a one-time claim link. Open it in the browser to take ownership of the Space, and the extension keeps publishing to it afterwards. See [Publish without an account](/anonymous-and-claim).

## Or use the hosted server

If you would rather connect to the hosted endpoint and sign in with OAuth, add this to `claude_desktop_config.json`.

```json claude_desktop_config.json
{
  "mcpServers": {
    "spacefast": {
      "type": "http",
      "url": "https://mcp.spacefast.com"
    }
  }
}
```

The hosted server has no filesystem, so `publish` requires inline files. Plugins and connectors you add to your Claude account sync down to Desktop; the bundle is the desktop-only lane.

:::note
`sf setup agent --agent claude-desktop` writes nothing. Claude Desktop is not one of the clients the CLI knows how to configure. Use the plugin, the extension, or the config file above.
:::
