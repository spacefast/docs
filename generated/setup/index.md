Pick the agent you already use. Every page leads with the best way to connect it and lists
the others, and the same Spacefast account works across all of them.

- [Claude](/agents/claude-app/): Add Spacefast to your Claude account once, and use it on the web, your phone, the desktop app, and Cowork.
- [ChatGPT](/agents/chatgpt/): Add Spacefast to ChatGPT on the web so it can publish what you build.
- [Cursor](/agents/cursor/): Add Spacefast to Cursor so its agent can publish what you build.
- [Antigravity](/agents/antigravity/): Add Spacefast to Antigravity so its agent can publish what you build.
- [Grok Bot](/agents/grok-bot/): Ask your Grok Bot to add Spacefast, or add the Spacefast plugin.
- [OpenClaw](/agents/openclaw/): Add Spacefast to OpenClaw as an MCP server, or give OpenClaw one prompt and it sets Spacefast up itself.
- [Raycast](/agents/raycast/): Add Spacefast to Raycast AI and call it with @Spacefast.
- [Muse](/agents/muse/): Give Muse one prompt and it sets up Spacefast itself.

- [Continue](/agents/continue/): use Cursor instead.
- [Roo Code](/agents/roo-code/): use Cline instead.
- [Jules](/agents/jules/): use Antigravity instead.

Not sure which way to connect? [Compare them](/connect/compare/). Anything else that can fetch a URL can publish too: point it at the [agent documentation](/agents/).
