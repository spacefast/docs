---
title: Next.js
description: Build a Next.js app with the bundled Spacefast adapter, or publish a static export from an older Next
---

Next.js is detected by its `next` dependency. A project that also depends on `nextra` matches the Nextra row instead, which builds and outputs the same way.

## What to build

The default `next build`. On Next 16.2 and 16.3, the CLI first points Next at the bundled `@spacefast/next-adapter` through the `NEXT_ADAPTER_PATH` environment variable, so there is nothing to add to `next.config`. The adapter opts the build into immutable static assets and writes down what Next produced for the classifier to read.

## Supported Next versions

| Next.js | Server-rendered build | `output: "export"` |
| --- | --- | --- |
| 16.2.x, 16.3.x | Yes, through the bundled adapter | Yes |
| 15.5.24 and later 15.5 releases | Yes | Yes |
| 14.2, 15.0 to 15.5.23, 16.0, 16.1, 16.4 | No | Yes |

Only stable releases count; canary and other prerelease versions are refused.

## The output directory

`out`.

## Publish

```bash
sf publish
```

## What the receipt shows

```text
Published: https://quiet-harbor.space.fast

  Live URL      https://quiet-harbor.space.fast
  Version URL   https://quiet-harbor--v3.space.fast
  Version       v3 (ready)
  Files         212
```

## The gotcha

A version outside the table, or a server-rendered build on a version that only supports exports, stops before it builds:

```text
next_version_unsupported
```

That is exit code 2. There is no guessing fallback, because a publish classified from guessed facts is worse than a refused one.

On an export-only version, set `output: "export"` and let `sf publish` build it. On an unsupported version, do the export yourself and upload it:

```js next.config.js
module.exports = { output: "export" };
```

```bash
npx next build
sf publish ./out --prebuilt
```

One related failure mode. If a custom build command runs `next build` in a way that loses the environment the CLI set, the adapter never runs. The publish then stops with `build_failed`, saying `.spacefast/next-build.json` was not written. Let the CLI invoke the build, or pass its environment through your wrapper.
