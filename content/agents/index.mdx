Connect your AI to Spacefast before you start building. Spacefast gives your agent the skills, recipes, MCP tools, and one Space (database, storage, Workers, auth, domains) so it makes fewer mistakes and ships straight to a live URL.

## Connect your AI

Paste this prompt into Claude, ChatGPT, Grok Bot, Muse, or any AI that can fetch URLs and make HTTP requests. No terminal is needed.

<Prompt description="Paste into your AI to connect Spacefast." actions={["copy"]}>
Fetch https://spacefast.com/setup.md and follow it.
</Prompt>

The setup guide distinguishes connected MCP/CLI clients, anonymous HTTP publishing (via `https://spacefast.com/publish-spec.json`), and full-stack apps so your agent takes the right path automatically. You can also connect straight from your AI app:

In the same conversation where you connect Spacefast, describe what you want to make and ask your AI to publish it. Publishing through your connected account saves the Space directly to your team with no claim step. New Spaces start private unless your team changed its default. Ask the agent for a viewer link, or open the Space in [your dashboard](https://my.spacefast.com) and choose **Access → Create share link → Can view**, then test it while signed out. To make edits, return to the same conversation and ask the agent to update that Space.

You can also publish without connecting an AI. Drag a folder or `.zip` onto [drop.fast](https://drop.fast) with no install or account (see [Publishing](/publish)), or push a Git repository to `push.fast` (see [Publish from Git](/git)).

### Spacefast plugin (recommended)

Claude Code, Codex, and Factory Droid each take the same plugin repository:

```bash
claude plugin marketplace add spacefast/plugins
claude plugin install spacefast@spacefast
```

Or use the universal installer for `claude-code`, `codex`, `cursor`, `vscode`, `github-copilot`, `grok`, and `kimi`:

```bash
npx -y plugins add spacefast/plugins -t cursor -y
```

Nothing assumes the `sf` CLI is already installed. In Claude, adding the Spacefast connector and plugin to your account syncs across web, mobile, and Claude Desktop — you don't need a separate desktop bundle. On a Claude Team or Enterprise plan, an owner must enable the connector first, and `sf setup agent` does not edit `claude_desktop_config.json`.

### Terminal setup (`npx spacefast setup`)

Run the zero-install setup wizard to sign in, configure detected agents, and publish the current directory:

```bash
npx -y spacefast setup
```

To configure agent tooling alone with an installed CLI, run [`sf setup agent`](/cli/reference#sf-setup-agent). By default it connects editors over `sf mcp proxy` using your CLI login, which helps when an editor lacks native MCP OAuth. See [`sf setup`](/cli/reference#sf-setup) for every flag.

### Direct MCP

Point any MCP client at `https://mcp.spacefast.com` for hosted OAuth, or run `npx -y spacefast mcp` for local stdio. Hosted MCP has no local filesystem access, so `publish` takes inline files or a completed `uploadId`. To publish a local folder by `path` over local MCP, install the standalone or Homebrew `sf` CLI on macOS or Linux; `npx`, the npm package on Node.js, and Windows take inline files. See [MCP server](/agents/mcp-server).

## What an agent can do

Agents call API operations directly through MCP, within the permissions you approve. Some actions, including team membership changes and billing changes, need you in the dashboard.

Use `publish` for files, `operation_status` for an active publish, and Space Apps for visual inspection. Call operation tools such as `searchDocs`, `getDocsPage`, and `listSpaces` directly. Continue a saved approval with `resume_execution`.

The [MCP reference](/agents/mcp-server#the-tools) links the current tool catalog and explains the runtime differences. Read the operation schema before calling it, and check a write with a read before reporting success.

If your team has a saved [Design System](/design-system), your agent can read its standards and files while working on a project. Ask it to apply the system to a new build or bring an existing project into line with the current rules.
