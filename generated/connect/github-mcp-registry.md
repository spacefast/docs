Install Spacefast from its page on github.com/mcp.

## How it works

1. Open Spacefast on github.com/mcp and choose the editor to install into.
2. The editor adds the hosted Spacefast server from the registry's record.
3. Sign in to Spacefast and approve access.

## What you need

- An editor that installs from the GitHub MCP Registry, such as VS Code.

## Best for

VS Code users who already browse github.com/mcp.
