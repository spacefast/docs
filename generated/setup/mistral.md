Connect Spacefast to Mistral Le Chat or Mistral Vibe using hosted MCP with OAuth.

**Add Spacefast in Mistral Le Chat** ([Hosted MCP server](/connect/hosted-mcp/)). Add Spacefast as a custom MCP connector in Mistral Le Chat using OAuth.

```text
https://mcp.spacefast.com
```

1. In Le Chat, open Intelligence → Connectors and choose Add Connector.
2. Name it Spacefast, paste the MCP server URL above, and complete browser OAuth sign-in.

Prefer to hand this off? Copy setup prompt:

```text
Fetch https://spacefast.com/setup.md
```

Give the agent one prompt that lets it choose and complete the best setup lane.
