Prices, allowances and limits for every plan are on [Pricing & Limits](/pricing). This page covers managing a plan.

## Upgrade, downgrade or cancel

Open your team's **Settings → Billing** to change or cancel a plan. Only owners and admins can change billing. Choose **Open billing portal** for invoices and payment methods.

Upgrades apply immediately and prorate to the day. Downgrades apply at renewal. Cancellation stops renewal, with access continuing until the paid period ends. There are no refunds. Review the price and effective date before confirming.

## Read the plan through the API

`GET /v1/teams/{teamId}/entitlements` and `GET /v1/teams/{teamId}/plan-policy` return the resolved `planCode` and limits. Plan codes are stable: `free` is Personal, `go` is Go, `plus` is Pro, and the others are `business`, `enterprise` and `internal`. `GET /v1/pricing` returns every plan's public prices and limits.

Use the returned entitlements for feature checks.

## When a payment fails

Your sites keep serving through a grace period, but you cannot change anything.

| Stage | How long | What visitors get | What you get |
| --- | --- | --- | --- |
| Past due | 7 days from the failed payment | Sites serve normally | Reads work. Every write returns `402` with code `tenant_past_due` |
| Suspended | After the grace period ends | Every space serves `402` and the text `This space is paused.` | Reads work. Every write returns `403` with code `tenant_suspended` |

Settle the payment in the billing portal to restore access. API reads remain available in either state.

## Billing is dashboard-only

Plans, checkout, and cancellation live in the dashboard. There is no `sf` command and no API endpoint for changing a plan. API keys and agent credentials cannot make those changes.

Agents can read [plan entitlements](#read-the-plan-through-the-api) and [usage](/usage) through the API.
