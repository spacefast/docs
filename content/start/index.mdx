Publish a folder, a zip, or a single `index.html`, and Spacefast serves it
at a permanent URL seconds after the upload completes. The first publish
does not require an account.

## Tell your agent

If you have a coding agent open, paste this:

```text
fetch https://spacefast.com/setup.md
and publish this space to Spacefast
```

The agent fetches the instructions, publishes, and reports back the live URL
and the permanent version URL. If it published without an account, it also
hands you a claim link. To make the setup permanent — CLI, skill, and MCP —
see [Set up an agent](/agents).

## Or run the CLI yourself

Install the CLI once:

```bash
curl -fsSL https://spacefast.com/install.sh | bash
```

Then publish your build output:

```bash
sf publish ./dist --name docs
```

`--name` sets the space title, and `--spa true` forces the single-page-app
fallback if Spacefast guesses your setup wrong. The receipt prints the live
URL, the permanent version URL, and — without an account — a claim link. The
full command surface is in the [CLI reference](/cli).

The first publish writes `.spacefast/state.json` next to the folder, so
later publishes from the same directory update the same space at the same
URL. Each changed publish creates a new immutable version, unchanged files
are never uploaded twice, and [`sf rollback`](/publish/versions) promotes an
earlier version with no rebuild.

## Claim your space

A space published without an account expires unless you claim it within 6
hours: open the claim link and sign in. After claiming, you keep the same
URL for every future publish and get full
[version history](/publish/versions). The details are on
[Publish without an account](/publish/anonymous).

:::tip
Spacefast looks for `index.html` at the root of what you publish. It never
runs server-executable files; everything is served as static content unless
you declare a [runtime](/apps).
:::

## No terminal at all

Open [drop.website](https://drop.website) and drag a folder, a zip, or an
`index.html` file onto the page. The upload publishes the same way as the
CLI and returns the same live URL, version URL, and claim link.

If you want to try the CLI without installing it, the
[Spacefast browser terminal](https://my.spacefast.com/terminal) gives you a
working shell with a small static site in `/workspace/site`:

```bash
cd /workspace/site
```

```bash
sf publish .
```

Run `sf --help` to explore, or `sf login` to manage spaces already in your
account; the terminal opens the device-login page in a new tab. It is a
browser sandbox rather than your computer, so commands that need local
files, installed packages, or a full operating system belong in the
[real CLI](/cli).
