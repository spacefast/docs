The Spacefast plugin lets Codex publish your project and manage your Spaces through the hosted MCP server.

## Install

```bash
codex plugin marketplace add spacefast/plugins
codex plugin add spacefast@spacefast
```

Two other ways to install: `npx -y plugins add spacefast/plugins -t codex -y` installs the same plugin, and `sf setup agent --agent codex` writes the MCP table into `$CODEX_HOME/config.toml` (default `~/.codex/config.toml`) and installs the skill into `$CODEX_HOME/skills/spacefast/`.

## What the plugin adds

### MCP server

```json .mcp.json
{
  "mcpServers": {
    "spacefast": {
      "type": "streamable-http",
      "url": "https://mcp.spacefast.com"
    }
  }
}
```

Codex uses the transport name `streamable-http` for the same endpoint that Claude Code and Cursor call `http`. The hosted server needs a signed-in connection, so anonymous publishing goes through `sf publish` instead.

### Skills

`skills/spacefast/` is the base skill, in the Codex variant. The plugin also ships the task skills for building a site, editing a Space, sharing, custom domains, fixing a deployment, and the Design System. Each skill has a `SKILL.md`, a `references.md`, and an `agents/openai.yaml` with its display name and default prompt. See [skills](/agents/skills).

### Hooks

The plugin includes the same two advisory hooks as [Claude Code](/agents/claude-code#hooks): a `SessionStart` note when the directory is linked to a Space, and a Design System reminder before publishing. Codex doesn't trust new or changed hooks on install. Review them with `/hooks` first.

### Agent manifest

`agents/openai.yaml` declares the plugin's identity and its one dependency, the Spacefast MCP server over `streamable_http` at `https://mcp.spacefast.com`, with `allow_implicit_invocation: true`.

## Manual config

To skip the plugin and add only the MCP server, put this in `~/.codex/config.toml`.

```toml ~/.codex/config.toml
[mcp_servers.spacefast]
url = "https://mcp.spacefast.com"
```

`sf setup agent --agent codex` writes the same table with an `oauth_resource` line, or the stdio form when you pick the proxy or local method.

```toml ~/.codex/config.toml
[mcp_servers.spacefast]
command = "sf"
args = ["mcp", "proxy"]
```
