## The three nouns that matter

- A **space** is a site or app with one stable live URL.
- A **publish** sends new output to that space.
- A **version** is an immutable snapshot. A successful publish moves the live
  URL to the new version atomically. A failed publish leaves the current site
  alone.

A root `index.html` is the ordinary homepage. Spacefast serves the files you
publish. It runs app code only when you explicitly choose Functions or Zero.
