Platform limits apply identically across every plan, while plan allowances scale per team and per Space on [Pricing and limits](/pricing).

## Enforcement

Read `GET /v1/teams/{teamId}/entitlements` and `GET /v1/teams/{teamId}/plan-policy` to inspect the active limits on a team.

- Blocked Space creation or claims return `409` with `quota_exceeded`.
- Domain and team-member caps return `domain_quota_exceeded` and `team_member_quota_exceeded`.
- The daily publish counter warns rather than blocking publishes. It pools direct publishes and CI builds and resets at `00:00` UTC.
- The storage usage counter reports overage without blocking writes. Neither warning counter is an invoice line item.

See [Versions](/versions#how-many-versions-are-kept) for version retention and deletion rules.

| File path length | 1,024 bytes | `path_too_long` |
| Manifest body | 16 MiB | `manifest_body_too_large` |
| Config file size (`sf.jsonc` or evaluated `spacefast.config.ts`) | 256 KiB | Config validation error |
| Templates in config | 100 | `config_templates_over_limit` |
| Cron jobs declared per Space | 8 (your plan sets how many run; see [Crons](/crons)) | Config validation error |

| Inject snippets or custom JavaScript tags | 16 per list, each 8 KiB | Config validation error |
| Redirect rules compiled | 2,100 total (2,000 static, 100 dynamic) | Routing compile error |

The 24 MiB Workers bundle limit applies on every plan and includes compiled JavaScript, embedded modules, and the manifest JSON. Every config key and parser cap is on [Configuration](/config-file). Routing rule syntax is on [Redirects and rewrites](/redirects) and [Headers](/headers).

## Anonymous publish caps

Publishing without an account uses stricter limits than the Personal plan:

| Cap | Value | When you hit it |
| --- | --- | --- |
| Largest single file | 50 MiB | `422` `version_file_too_large` |
| Total bytes per version | 100 MiB | `422` `version_total_bytes_exceeded` |
| Files per version | 1,000 | `422` `manifest_too_many_files` |
| Inline publish body | 100 MiB | `publish_inline_limit_exceeded` |
| Publishes per IP per hour | 20 | `429` `anonymous_publish_rate_limited` |
| Publishes per network fingerprint per hour | 60 | `429` `anonymous_publish_rate_limited` |
| Publishes per unclaimed Space per hour | 20 | `429` `anonymous_publish_rate_limited` |
| Unclaimed Spaces open at once | 10 per fingerprint | `429` `anonymous_space_limit_reached` |
| Active share links per unclaimed Space | 50 | Blocked |

Until you claim a Space, Spacefast serves a restricted set of content types: text, images, fonts, JSON, web manifests, JavaScript, PDF, gzip, XML, RSS, and Atom. Other file types upload without serving until you claim the Space. See [Anonymous publish and claiming](/agents/anonymous-and-claim).

## Retention windows

| What | Window | What happens at the end |
| --- | --- | --- |
| Unclaimed Space | {{anonymous-ttlSeconds}} from creation or the latest publish that changes files, capped at {{anonymous-publishAbsoluteCapSeconds}} from creation | The Space stops serving |
| Claiming an expired anonymous Space | 7 more days | The claim link stops working |
| Unfinished publish drafts | 24 hours | The draft expires and cannot be resumed; it stays in version history |
| Deleted team | 30 days | You can no longer restore the team; records remain stored |
| Past-due account | 7 days | Spacefast suspends the account and its Spaces stop serving |
| Activity history | Plan window, see [Pricing and limits](/pricing) | Hidden from listings, not deleted |
| Logs | Plan window, see [Pricing and limits](/pricing) | Queries clamp to the window |

Spacefast does not permanently delete records when a window ends. Most deletes are soft deletes: the record stops appearing in normal listings, and Spacefast handles permanent data removal on request.

An unclaimed Space that stops serving at its expiry deadline remains recoverable through its claim link for 7 more days. Loading the claim page when less than 1 hour remains extends the deadline by 1 hour at a time, up to 6 hours total. See [Anonymous publish and claiming](/agents/anonymous-and-claim).

## What a paused or removed Space serves

A Space that stops serving returns a specific status code and message instead of a blank 404:

| Situation | Status | Body | Writes to the Space |
| --- | --- | --- | --- |
| Account past due, inside grace period | Serves normally | Your Space | `402` `tenant_past_due` |
| Account suspended | `402` | `This space is paused.` | `403` `tenant_suspended` |
| Space disabled, expired, or taken down | `404` | `This space is no longer available.` | `409` with disable reason |
| Removed after a legal complaint | `451` | `This content is unavailable for legal reasons.` | `409` |
| Removed under strictest safety category | `404` | `This space hasn't been published yet.` | `409` |

During the grace period, a past-due account keeps serving Spaces while blocking writes in the dashboard, CLI, and API. Once suspended, it stops serving Spaces as well.

You can customize the legal-removal and no-longer-available pages like other error pages. The strictest-safety response matches an unpublished hostname (`404` with `X-Spacefast-Undeployed: 1`).

## Rate limits

Exceeding a rate limit returns `429` `rate_limited`. See [Rate limits](/api/rate-limits#headers) for response headers and backoff guidance.

The general `/v1` request budget uses a fixed 60-second window:

| Caller | Requests per minute |
| --- | --- |
| Authenticated, per credential | 600 |
| Anonymous, per IP | 300 |

Publishing, remote builds, and Space creation also carry hourly budgets per credential and per team that scale with your plan. Read `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset`, and `Retry-After` on responses for active limits. See [Rate limits](/api/rate-limits) for full behavior and [Errors](/api/errors) for every error code.
