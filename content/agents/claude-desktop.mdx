Connectors and plugins you add to your Claude account sync straight into Claude Desktop. You do not need to download or install a separate desktop bundle.

## Connect your Claude account (recommended)

Add Spacefast once on your Claude account, and it works across Claude Desktop, Claude on the web, and mobile.

<Steps>
  <Step title="Add the Spacefast connector">
    Open the [Spacefast connector in the Claude directory](https://claude.ai/directory/b0989c59-00b4-40db-a6d1-1e591ce2516c) and choose **Connect**.
  </Step>
  <Step title="Sign in and approve">
    Sign in to Spacefast and approve the permissions you want Claude to have.
  </Step>
  <Step title="Add the Spacefast plugin (optional)">
    In Claude, open **Plugins → Add → Add marketplace → Add from a repository**, enter `spacefast/plugins`, and add the Spacefast plugin so Claude also loads Spacefast skills.
  </Step>
</Steps>

Then ask Claude Desktop to verify the connection:

<Prompt description="List my Spacefast Spaces." actions={["copy"]}>
List my Spacefast Spaces.
</Prompt>

<Prompt description="Publish this page to Spacefast and give me the live URL." actions={["copy"]}>
Publish this page to Spacefast and give me the live URL.
</Prompt>

## Configure MCP in `claude_desktop_config.json`

If you want to publish local folders directly from your computer or configure MCP without syncing from your Claude account, add Spacefast to `claude_desktop_config.json`.

### Local stdio MCP (for local files)

Runs the Spacefast MCP server on your machine so Claude Desktop can read folders on disk and access connected tools through `search_connector_tools`:

```json claude_desktop_config.json
{
  "mcpServers": {
    "spacefast": {
      "command": "npx",
      "args": ["-y", "spacefast", "mcp"]
    }
  }
}
```

Ask Claude to sign you in when you first use it — it shows a link and a code, and approves both the MCP server and the `sf` CLI on this computer. Signed out, an anonymous publish returns a claim link; see [Publish without an account](/anonymous-and-claim).

### Hosted MCP

Connect directly to the hosted endpoint and sign in with OAuth:

```json claude_desktop_config.json
{
  "mcpServers": {
    "spacefast": {
      "type": "http",
      "url": "https://mcp.spacefast.com"
    }
  }
}
```

The hosted server has no local filesystem access, so `publish` takes inline files.

:::note
`sf setup agent` does not edit `claude_desktop_config.json`. Use your Claude account connector or add one of the entries above.
:::
