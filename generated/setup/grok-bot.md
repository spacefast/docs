Connect a Grok Bot to Spacefast with a custom Remote HTTPS MCP server.

**Copy the setup prompt.** Ask your Bot to add Spacefast, or use its Plugins setup card.

```text
Add a custom MCP server called Spacefast using Remote HTTPS at https://mcp.spacefast.com. Let me complete the OAuth sign-in.
```

1. Paste this prompt into your Bot's chat, or open its info pane and choose Setup → Plugins.
2. Use a custom MCP server with Remote HTTPS and the server URL above.
3. Complete the Spacefast OAuth sign-in when asked.

For a Team Bot, its owner or a manager changes the shared setup. Each teammate signs in with their own account.
