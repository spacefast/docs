A Space's entire lifecycle, from creation to transfer, runs through this one set of terminal commands.

A Space is a slug, a hostname, an owner, and a stack of versions. See [Spaces](/spaces) for the model.

## How the CLI picks a Space

Most subcommands take `--space`. When you leave it out, the CLI resolves in this order:

1. `--space` or `SPACEFAST_SPACE`
2. The anonymous Space saved in `.spacefast/state.json`, unless the committed link names a different Space ID
3. The committed link in `.spacefast/space.json`
4. A `space` entry in `sf.jsonc`
5. The `spaceId` cached in `.spacefast/state.json`

With nothing to go on and exactly one accessible Space, the CLI picks it, in scripts too. With several, an interactive terminal gets a prompt and a non-interactive one gets `no_space_selected` (exit 2). An empty `--space` or `SPACEFAST_SPACE` is an error, not "absent".

## sf spaces list

List spaces. Alias: `sf spaces ls`.

```text
sf spaces list
```

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `-T, --team=<value>` | all teams | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--limit=<value>` | `50` | Maximum spaces to return. 1 to 100 |
| `--cursor=<value>` | none | Continue from the cursor a previous page printed |
| `--inactive-for=<days>` | none | Only list the team's Spaces with no publish or change in this many days |

### Examples

```bash
sf spaces list
sf spaces list --team acme
```

### Output

A table of `SLUG`, `ID`, `TEAM`, `LIVE URL`. `--json` returns `{ data: [...], pagination }`, one Space object per row with `id`, `slug`, `title`, `teamSlug`, `status`, `defaultHostname`, `liveUrl`, `anonymous`, `config`, and timestamps.

## sf spaces inspect

Show a space.

```text
sf spaces inspect
```

Prints the Space's live runtime state and its current version.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--space=<value>` | linked Space | Space ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `-T, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |

### Examples

```bash
sf spaces inspect
sf spaces inspect --space docs
```

### Output

```text
Space:    Docs
Slug:     docs
Status:   active
Live URL: https://docs.space.fast
Team:     acme
Mode:     website
```

Then the live version summary, or `Live version: none`. An anonymous Space prints `Team: anonymous` and a `Claim expires:` line. `--json` returns `{ space, state, runtime, liveVersion }`.

## sf spaces check

Check whether a space name is available.

```text
sf spaces check NAME
```

Normalizes the name to a slug, then checks the slug and its managed hostname in the team. The answer is advisory, because another create or rename can still take the name first. Reserved names fail, and so do slugs that contain `spacefast`, `stattic`, `automattic`, `wordpress`, or `paypal`. A space slug is at most 55 characters. Requires a login or `--token` that can create Spaces in the team.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<name>` | required | Space name or slug to check |

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `-T, --team=<value>` | default team | Team to check the name in. Slug, ID, or name. Env `SPACEFAST_TEAM` |

### Example

```bash
sf spaces check my-site --team acme
```

### Output

```text
Normalized name: my-site
Space slug: available
Space slug suggestion: none
Managed hostname (my-site.space.fast): available
Managed hostname suggestion: none
Advisory only: creating or renaming a space can still lose an availability race.
```

When a name is taken, the suggestion lines name the closest free slug and hostname label. A name with nothing usable prints `Normalized name: empty` and is unavailable. `--json` returns the [`getSlugAvailability`](/api/reference/spaces/getslugavailability) result unchanged: `kind`, `normalizedSlug`, `available`, `suggestion`, and the hostname fields.

### Errors

| Code | Exit | What to do |
| --- | --- | --- |
| `unauthorized` | 10 | No credential. Run `sf login` |
| `not_found` | 20 | No team matches `--team`. Run `sf teams list` |
| `forbidden` | 11 | You can't create Spaces in that team |
| `missing_scope` | 2 | You belong to several teams and none was picked. Pass `--team` |

## sf spaces create

Create an empty Space.

```text
sf spaces create
```

Creates the Space and saves it to `.spacefast/state.json`. You rarely need this: `sf publish` creates a Space when there is none.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--git=<value>` | none | Start from a repository: a Source-available Spacefast Space, or a public github.com or gitlab.com repository |
| `--path=<value>` | repository root | Copy only this folder of the `--git` repository, as one commit at the new root |
| `--ref=<value>` | default branch | Branch, tag, or commit of the `--git` repository to copy |
| `-T, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--name=<value>` | none | Set the Space title |
| `--slug=<value>` | generated | Set the Space slug |
| `--mode=website\|files` | `website` | Space serving mode |
| `--spa=auto\|true\|false` | `auto` | Control single-page app fallback detection |
| `--hostname-scope=team\|global` | server default | Managed hostname scope for newly created Spaces |
| `--save-state` / `--no-save-state` | `--save-state` | Write the created Space to `.spacefast/state.json` |
| `--show-secret` | off | Print the access URL and claim link in JSON or non-interactive output |

### Example

```bash
sf spaces create --name docs
```

### Output

The Space summary. `--json` returns the created Space with its state entry. A new team-owned Space has no automatic share link, so the receipt can omit `access`. The owning team signs in at the live URL. Create a [share link](/share#share-links) when you need one. Any access URL or claim link in a receipt is masked unless you pass `--show-secret`.

## sf spaces update

Rename or update a space.

```text
sf spaces update
```

Patches Space identity, serving metadata, and generated viewer metadata.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--[no-]noindex` | unchanged | Ask search engines not to index the live Space. `--no-noindex` allows indexing |
| `--space=<value>` | linked Space | Space ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `-T, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |
| `--slug=<value>` | unchanged | New Space slug. Must be sent without other update flags |
| `--name=<value>` | unchanged | Space title |
| `--mode=website\|files` | unchanged | Serving mode |
| `--spa=auto\|true\|false` | unchanged | Enable or disable SPA fallback. `auto` leaves the current setting alone |
| `--viewer-title=<value>` | unchanged | Viewer page title. Pass `null` to clear |
| `--viewer-description=<value>` | unchanged | Social preview description. Pass `null` to clear |
| `--viewer-og-image-path=<value>` | unchanged | Social preview image path. Pass `null` to clear |
| `--wait` / `--no-wait` | `--wait` | Wait until queued work finishes before returning |
| `--wait-timeout=<seconds>` | `900` | Seconds to wait for queued work to finish |

### Examples

```bash
sf spaces update --space docs --slug developers --wait
sf spaces update --space docs --name "Developer docs"
sf spaces update --space docs --mode files --spa false
```

A slug change also renames the managed hostname. Version URLs are unaffected because they are minted once and survive renames. See [URLs and hostnames](/urls).

## sf spaces download

Download a space version.

```text
sf spaces download
```

Downloads the files of one version. Defaults to the latest.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--space=<value>` | linked Space | Space ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `-T, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |
| `--version=<value>` | `latest` | Version ID, ref, number, or `latest` |
| `--output=<value>` | `.` | Directory to write downloaded files into |
| `--force` | off | Overwrite files that already exist in the output directory |
| `--concurrency=<value>` | `10` | Files to download at the same time. Minimum 1 |

### Examples

```bash
sf spaces download --space docs --output ./out
sf spaces download --space docs --version v3 --force
```

### Output

The Space summary, then `Downloaded 12 files from v3 to ./out`. `--json` returns `{ space, version, output, concurrency, fileCount, files }`.

## sf spaces duplicate

Duplicate a space.

```text
sf spaces duplicate
```

Downloads an existing version and publishes those files as a new Space.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--space=<value>` | linked Space | Source Space. ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `-T, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |
| `--version=<value>` | live version | Version to duplicate |
| `--slug=<value>` | generated | Slug for the duplicate Space |
| `--title=<value>` | source title | Title for the duplicate Space |
| `--wait` / `--no-wait` | `--wait` | Wait until queued work finishes before returning |
| `--wait-timeout=<seconds>` | `900` | Seconds to wait for the duplicate to become ready |

### Example

```bash
sf spaces duplicate --space docs --slug docs-copy
```

## sf spaces claim

Claim an anonymous space.

```text
sf spaces claim
```

Moves a saved anonymous Space into your account, starting browser login if you are not signed in. The space key comes from `.spacefast/state.json` unless you pass `--claim-token`.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--[no-]open` | on | Open the browser. `--no-open` prints the link instead |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |
| `--space=<value>` | saved Space | Space ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `-T, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--keep-publishing` / `--no-keep-publishing` | prompted | Keep the agent that published this Space authorized to publish to it |
| `--wait` / `--no-wait` | `--wait` | Wait until queued work finishes before returning |

### Examples

```bash
sf spaces claim
sf spaces claim --space spc_xxx --claim-token sfc_xxx --team my-team
```

### Output

```text
Claimed: https://docs.space.fast

This space is now saved to your account.
Space spc_…
Team acme
```

With `--keep-publishing`, one more line: `The publishing agent stays authorized for one credential upgrade.` Run `sf continue` afterwards to swap the saved space key for a durable API key. See [Anonymous publish and claiming](/anonymous-and-claim).

## sf spaces key rotate

Rotate an anonymous Space's key.

```text
sf spaces key rotate
```

Replaces an anonymous Space's key, live URL, and claim link. Recipient Links keep working. Use it when the old key leaked.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--space=<value>` | saved Space | Space ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |

### Example

```bash
sf spaces key rotate
```

### Output

```text
Rotated the space key for spc_….
Claim link: https://…
Saved the replacement space key to .spacefast/state.json.
```

## sf spaces archive

Stop serving a Space and keep its versions, source, database, storage, and domains. Repeat `--space` to archive several Spaces in one run.

```bash
sf spaces archive --space docs
sf spaces archive --team acme --space old-report --space q3-dashboard
```

## sf spaces restore

Resume serving an archived Space with its retained versions, data, and domains.

```bash
sf spaces restore --space docs
```

## sf spaces delete

Delete a space. Aliases: `sf spaces rm`, `sf spaces del`.

```text
sf spaces delete
```

Takes the Space offline. The slug, versions, and data are retained rather than destroyed. The prompt names the resolved slug, and a non-interactive run needs `--yes`.

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--space=<value>` | linked Space | Space ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `-T, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |
| `--wait` / `--no-wait` | `--wait` | Wait until queued work finishes before returning |

### Examples

```bash
sf spaces delete --space docs
sf spaces delete --space docs --yes
```

### Output

```text
Space spc_… is offline.
Its slug, versions, and data are retained for operator cleanup.
Operation: op_… (completed)
```

If the checkout was linked to that Space, the link is cleared.

### Errors

| Code | Exit | What to do |
| --- | --- | --- |
| `confirmation_required` | 2 | Non-interactive run without `--yes`. Pass `--yes` |
| `cancelled` | 130 | You declined the prompt |

## sf spaces transfer

Transfer a space to another team.

```text
sf spaces transfer TEAM
```

Requests a transfer. It applies once a member of the target team accepts.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<team>` | required | Target team slug, ID, or name |

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--space=<value>` | linked Space | Space ID, live URL, domain, or slug. Env `SPACEFAST_SPACE` |
| `-T, --team=<value>` | default team | Source team. Slug, ID, or name. Env `SPACEFAST_TEAM` |
| `--claim-token=<value>` | saved key | Space key (`sfc_…`) for an unclaimed anonymous Space. Env `SPACEFAST_CLAIM_TOKEN` |

### Example

```bash
sf spaces transfer acme --space spc_123
```

### Output

The transfer block (`Transfer`, `Space`, `Status`, `From team`, `To team`, `Expires`), then `Next: a member of the target team accepts with sf transfers accept <id>.` `--json` returns `{ transfer }`.

### Errors

| Code | Exit | What to do |
| --- | --- | --- |
| `validation_error` | 2 | No accessible team matches the name. Run `sf teams list` |

## sf transfers list

List a team's incoming and outgoing Space transfers. Alias: `sf transfers ls`. It needs transfer authority, which team owners and admins hold, and shows pending transfers by default, up to the newest 100.

| Flag | Default | What it does |
| --- | --- | --- |
| `--status=<pending_confirmation\|completed\|canceled\|expired>` | pending | Filter by transfer status |
| `--space=<value>` | none | Filter by Space ID (`spc_…`) |

```bash
sf transfers list --team acme
```

## sf transfers inspect

`sf transfers inspect TRANSFER` shows a transfer's parties, status, and expiry.

```bash
sf transfers inspect trf_123
```
