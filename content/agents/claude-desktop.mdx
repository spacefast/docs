The Spacefast desktop extension runs the Spacefast MCP server on your computer, so Claude Desktop can publish and manage your Spaces. It needs Node.js with `npx` where Claude Desktop can find it.

## Install the extension

Download `claude-desktop.mcpb` from the latest release of `github.com/spacefast/plugins` and open it. Claude Desktop installs it as a desktop extension. If the bundle doesn't open, go to **Settings → Extensions → Advanced settings → Install Extension** and select the file.

## What the manifest declares

The bundle is a manifest version `0.2` extension with a Node server. Its entry point is `server/index.js`, a thin spawner that runs `npx -y spacefast@<version> mcp` over stdio, so the extension itself carries no server code.

```json manifest.json
"mcp_config": {
  "command": "node",
  "args": ["${__dirname}/server/index.js"]
}
```

The extension publishes inline files and edits Space source without a local checkout. Because the extension runs on Node, it can't publish a local folder by path. That needs the native `sf` build on Linux or macOS. From the extension, publish inline files, or use the CLI.

| Fact | Value |
|---|---|
| Manifest version | `0.2` |
| Server type | `node` |
| Platforms | macOS, Windows, Linux |
| Node | 20 or newer |
| License | MIT |
| Tools | Generated from the pinned CLI's tool catalog |

## Authentication

The extension has no settings. Ask Claude to sign you in: it shows a link and a code, and you approve them in the browser. That signs in both the extension and the `sf` CLI on this computer.

Signed in, the extension can also reach services your team connected in Spacefast through `search_connector_tools`. The hosted server can't.

Signed out, an anonymous publish returns a claim link. Open it in the browser to take ownership of the Space. See [Publish without an account](/anonymous-and-claim).

## Or use the hosted server

If you would rather connect to the hosted endpoint and sign in with OAuth, add this to `claude_desktop_config.json`.

```json claude_desktop_config.json
{
  "mcpServers": {
    "spacefast": {
      "type": "http",
      "url": "https://mcp.spacefast.com"
    }
  }
}
```

The hosted server has no filesystem, so `publish` requires inline files. Connectors you add on claude.ai sync down to Desktop; the bundle is the desktop-only option.

:::note
`sf setup agent` doesn't configure Claude Desktop. Use the extension or the config file above.
:::
