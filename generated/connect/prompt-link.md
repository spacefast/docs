A link that opens the agent with a setup prompt already typed in.

## How it works

1. Open the link. The agent opens with the Spacefast setup prompt in its message box.
2. Send it. The agent follows the prompt and asks you to approve anything it installs.

## What you need

- An agent that accepts prompt links. Long prompts may be cut off.

## Best for

Agents that set up connectors themselves when asked.

## Agents that support it

- [Grok Bot](/setup/grok-bot/)

## Plan limits

### Grok Bot

- **Premium, Super and Ultra:** Grok Bot comes with these plans. Plus and Free don't include it. ([source](https://docs.x.ai/x-subscription/grok-bot), checked 2026-11-14)
- **Team bots:** An admin's MCP policy can block the server, and then it can't be saved. ([source](https://docs.x.ai/grok-bot/computer-and-apps), checked 2026-11-14)
