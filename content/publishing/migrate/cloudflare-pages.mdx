---
title: Cloudflare Pages
description: How to move a static site from Cloudflare Pages to Spacefast.
---

Keep Cloudflare Pages `_redirects` and `_headers` at the publish root. Common
path redirects, splats, placeholders, browser redirects, local `200` rewrites,
and supported custom response headers carry over. Check the target team's
[routing entitlements](/account/billing) before relying on Basic Auth or external
proxies.

```text
# _redirects
/docs/* /guides/:splat 301
/app/* /index.html 200
```

## What carries over

- Root `_redirects` and `_headers` files for the supported static routing surface.
- Path redirects, splats, placeholders, local rewrites, and supported response headers.
- `_headers` Basic Auth when enabled for the target team.
- Omitted redirect statuses continue to default to `302`.

## What to change

- Replace Pages Functions, `_worker.js`, Workers bindings, Bulk Redirects, and
  `_routes.json` behavior with static output, external services, or application
  code.
- Use external `200` proxy rules for public upstream APIs.
  Cloudflare-specific request mutation, bindings, and private credential
  injection do not run on Spacefast.
- Spacefast rejects platform-owned headers and CDN cache headers with diagnostics.
- Keep building on push. [Connect the repo](/publishing/git) —
  `sf git connect --platform-preset cloudflare-pages` imports build settings from
  your existing Pages config. You can also publish built output from CI, an
  agent, or the CLI.
