Spacefast hosts static sites for people and the agents building with them. Give
it HTML, CSS, JavaScript, Wasm, and assets; get a stable live URL without
babysitting a server.

## The useful mental model

- A **space** is your site or project. It has one stable live URL.
- A **publish** sends a static file, folder, archive, or detected project build.
- A **version** is an immutable snapshot with its own URL. A successful publish
  moves the live URL to that version atomically.
- Publishing the same content again is a no-op. Changed content becomes a new
  version.

A root `index.html` is the ordinary homepage. Spacefast serves the files you
upload; it does not execute uploaded server code.
