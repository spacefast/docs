Use `sf teams` to create or select a team and set defaults for new Spaces. Adding a member requires [Plus](/billing#seats); CLI credentials can list members and invitations, but invitation and membership changes require the dashboard. [`sf login`](/authentication#log-the-cli-in) stores an API key, not a browser session. See [credential limits](/api-keys#what-an-agent-grant-cannot-do).

A team owns Spaces, domains, and billing. Every member holds one team role: `owner`, `admin`, or `member`. See [Teams](/teams) for the model, and [`sf share`](/cli/share) for per-Space access, which is a separate system.

Most subcommands accept `-o, --team` (slug, ID, or name; env `SPACEFAST_TEAM`). Without it they use the default team set by `sf teams switch`.

## sf teams ls

List teams. Alias: `sf teams list`.

```text
sf teams ls
```

Lists teams available to the current login.

### Example

```bash
sf teams ls
```

### Output

A table of `TEAM` and `ID`, with `*` marking the default team. `--json` returns `{ teams, defaultTeamId }`, each team carrying `id`, `name`, `slug`, and `role`.

## sf teams switch

Set default team.

```text
sf teams switch [TEAM]
```

Sets the default team for future CLI publishes. The selection is stored per login and cleared when you log in again. It can never outlive the identity that made it.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `[team]` | prompted | Team slug, ID, or name |

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `-o, --team=<value>` | none | Team slug, ID, or name, as an alternative to the positional. Env `SPACEFAST_TEAM` |

### Example

```bash
sf teams switch acme
```

### Output

`Default team: acme`. `--json` returns `{ team }`.

### Errors

| Code | Exit | What to do |
| --- | --- | --- |
| `validation_error` | 2 | No stored login. Run `sf login` first |

## sf teams create

Create a team. Alias: `sf teams add`.

```text
sf teams create NAME
```

Creates a team owned by the current login.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<name>` | required | Display name for the new team |

### Example

```bash
sf teams create "Acme Inc"
```

### Output

```text
Created team acme.
Team: team_…
```

`--json` returns `{ team }`.

## sf teams accept

Accept a team invitation.

```text
sf teams accept INVITATION
```

Accept the invitation through its join link in the dashboard. With CLI credentials, this request is refused with `403 authorization_level_not_allowed`. Once you accept in the dashboard, credentials approved for all teams can see the new team.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<invitation>` | required | Invitation ID from the invite link |

## sf teams defaults

Manage future-space defaults.

```text
sf teams defaults [ROOTACCESS]
```

Shows or sets the access preset materialized for Spaces this team creates in the future. It never changes an existing Space.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `[rootAccess]` | show only | Future Space preset: `private`, `team`, or `public` |

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `-o, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |

### Examples

```bash
sf teams defaults
sf teams defaults private
```

### Output

```text
New Spaces: private
This setting affects future spaces only.
```

`--json` returns `{ teamId, defaults }`. To override the preset for one publish, pass `sf publish --access`. To change an existing Space, use [`sf share`](/cli/share).

## sf teams members rm

Remove a team member. Aliases: `sf teams members remove`, `sf teams members delete`.

```text
sf teams members rm MEMBER
```

Remove the member from the dashboard under **Members**. With CLI credentials, this request is refused with `403 authorization_level_not_allowed`.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<member>` | required | Member ID or email |

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `-o, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |

## sf teams invitations add

Create a team invitation. Alias: `sf teams invitations create`.

```text
sf teams invitations add EMAIL
```

Send the invitation from the dashboard under **Members → Invite member**. With CLI credentials, this request is refused with `403 authorization_level_not_allowed`.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<email>` | required | Email address to invite |

### Flags

| Flag | Default | What it does |
| --- | --- | --- |
| `--role=owner\|admin\|member` | `member` | Role to grant when the invitation is accepted |
| `-o, --team=<value>` | default team | Team slug, ID, or name. Env `SPACEFAST_TEAM` |

## sf teams invitations resend

Resend a team invitation.

```text
sf teams invitations resend INVITATION
```

Resend the invitation from the dashboard under **Members → Pending**. With CLI credentials, this request is refused with `403 authorization_level_not_allowed`.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<invitation>` | required | Invitation ID |

## sf teams invitations cancel

Cancel a team invitation.

```text
sf teams invitations cancel INVITATION
```

Cancel the invitation from the dashboard under **Members → Pending**. With CLI credentials, this request is refused with `403 authorization_level_not_allowed`. Passing `--yes` only skips the CLI confirmation; it does not grant permission.

### Arguments

| Argument | Default | What it is |
| --- | --- | --- |
| `<invitation>` | required | Invitation ID |
